# Job Search Portal Frontend Revamp

A React 18 + TypeScript demo job-search portal with Redux Toolkit state, responsive Tailwind styling, saved jobs, filters, Jest/Testing Library tests, Cypress smoke coverage, and a GitHub Actions CI workflow.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Run checks with `npm test`, `npm run build`, and (with the app running) `npm run cypress:run`.

## Notes

This is a self-contained portfolio implementation using seeded sample jobs and browser-side state. The performance, traffic, team-size, and coverage figures in the originating project brief are target/claimed project metrics and are not independently measured by this scaffold. Replace sample data and connect your production API before presenting it as a deployed service.
